# 项目规则

## 项目详细分析

### 1. 项目概述
这是一个名为"record-manager"的视频管理应用（版本2.0.8），专门用于管理和处理小米摄像头的录像文件。它是一个基于Electron的桌面应用程序，结合Vue.js前端框架，采用TypeScript开发。

### 2. 技术栈
- **主进程**: Electron + TypeScript
- **渲染进程**: Vue 3 + TypeScript
- **状态管理**: Pinia
- **数据库**: SQLite3
- **路由**: Vue Router
- **构建工具**: electron-vite + Vite
- **打包工具**: electron-builder

### 3. 项目架构
- **主进程** (`src/main/`): 负责文件系统操作、数据库管理、FFmpeg视频处理
- **渲染进程** (`src/renderer/`): 提供用户界面，包括视频预览、搜索、管理等功能
- **预加载脚本** (`src/preload/`): 提供安全的API桥接
- **数据桥接** (`src/bridge/`): 定义数据类型和通信协议

### 4. 核心功能模块

#### 主要业务功能：
- **视频管理**: 自动扫描、分类和管理多个存储路径的视频文件
- **项目管理**: 支持创建和打开项目，管理多个数据仓库
- **标签系统**: 为视频文件添加标签，便于分类检索
- **缩略图生成**: 自动生成视频缩略图，提升浏览体验
- **回收站功能**: 删除的视频文件移至回收站，而非直接删除
- **视频预览**: 在应用内预览视频文件
- **批量操作**: 支持多选视频进行批量删除、标记等操作

#### 技术功能：
- **数据库管理**: 使用SQLite3存储文件信息、标签和关联关系
- **FFmpeg集成**: 处理视频压缩、裁剪等操作
- **IPC通信**: 主进程与渲染进程间的高效通信
- **异步任务队列**: 处理耗时操作，避免阻塞UI

### 5. 数据模型
- **File**: 视频文件信息（ID、路径、时长、大小、状态等）
- **Tag**: 标签信息（ID、名称、颜色）
- **FileTag**: 文件与标签的关联关系
- **Project**: 项目配置信息

### 6. 用户界面
- **主界面**: 视频预览和缩略图展示
- **管理界面**: 项目设置、标签管理
- **搜索界面**: 按条件搜索视频文件
- **操作面板**: 视频标记、删除、裁剪等操作

## 项目规则

### 1. 代码规范
- 使用TypeScript编写，注重类型安全
- 遵循ESLint和Prettier代码风格
- 组件化开发，模块职责单一

### 2. 数据流规则
- 主进程负责数据处理和持久化
- 渲染进程负责UI展示和用户交互
- 通过IPC进行跨进程通信
- 使用统一的数据类型定义

### 3. 文件管理规则
- 视频文件存储在多个数据仓库中
- 删除操作将文件移至回收站而非物理删除
- 自动为视频生成缩略图并存储在指定目录
- 支持多路径视频文件的统一管理

### 4. 任务处理规则
- 使用任务队列处理长时间运行的操作
- 防止并发冲突，确保数据一致性
- 提供进度反馈和错误处理

### 5. 性能优化规则
- 生成视频缩略图以提升浏览性能
- 支持按需加载大量视频文件
- 使用数据库索引优化查询性能

### 6. 用户体验规则
- 提供直观的界面操作
- 支持批量操作提高效率
- 实现快捷键和多选功能
- 提供操作反馈和历史消息

### 7. 配置管理规则
- 支持项目级别的配置管理
- 可自定义数据仓库路径和缩略图存储位置
- 配置信息持久化存储

### 8. 安全规则
- 通过预加载脚本限制渲染进程权限
- 验证用户输入，防止恶意路径访问
- 使用上下文隔离保护应用安全

这个项目是一个功能完备的视频管理工具，特别适用于监控录像的整理和管理，具有良好的扩展性和用户体验。
