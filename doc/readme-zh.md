视频剪辑工具使用手册

# 1 简介

## 1.1 软件概述

视频剪辑工具（Record Manager）是一款专注于视频分析、剪辑、裁剪的桌面应用程序。该软件提供视频分片编辑、关键帧提取、视频片段导出等核心功能，同时支持监控视频文件的批量管理。高度适合处理小米摄像头等安防监控录像，也支持任意视频文件的编辑处理。

![文件管理主页面](image/readme-zh/app_demo.jpg)

## 1.2 设计目标

本系统旨在解决视频处理中的核心需求：
- **视频片段快速剪辑**：精准定位、拆分、删除、导出
- **关键内容提取**：自动提取关键帧，快速预览视频内容
- **批量视频处理**：支持多文件管理与批量操作
- **存储空间优化**：智能压缩策略，保留核心信息

## 1.3 核心功能

### 1.3.1 视频剪辑（核心功能）

| 功能 | 描述 |
|-----|------|
| **分片拆分** | 在播放位置精准拆分视频片段 |
| **片段删除** | 标记删除不需要的片段 |
| **片段恢复** | 恢复误删的片段 |
| **导出剪辑** | 将保留的片段导出为新视频文件 |
| **拖拽打开** | 直接拖拽视频文件到界面即可编辑 |

### 1.3.2 视频分析

| 功能 | 描述 |
|-----|------|
| **关键帧提取** | 自动提取视频关键帧，快速预览内容 |
| **缩略图生成** | 生成视频缩略图网格，一目了然 |
| **帧精确定位** | 逐帧前进/后退，精准定位编辑点 |
| **变速播放** | 0.5x ~ 4x 倍速播放，快速浏览 |

### 1.3.3 文件管理（辅助功能）

| 功能 | 描述 |
|-----|------|
| **批量导入** | 扫描文件夹，批量导入视频文件 |
| **标签分类** | 为视频添加标签，便于分类检索 |
| **回收站** | 软删除机制，防止误删 |
| **搜索过滤** | 按时间、标签、大小等条件筛选 |

## 1.4 适用场景

- **视频剪辑**：快速裁剪视频，移除冗余内容，保留精彩片段
- **监控录像处理**：筛选有价值的监控片段，删除无用录像
- **视频内容分析**：通过关键帧快速了解视频内容
- **存储空间优化**：删除冗余视频，释放存储空间

## 1.5 支持格式

支持常见的视频格式：
- `.mp4`, `.avi`, `.mkv`, `.mov`, `.wmv`, `.flv`, `.webm`

# 2 系统要求与安装

## 2.1 系统兼容性

- Microsoft Windows 10 (64位)
- Microsoft Windows 11 (64位)

## 2.2 硬件要求

正常可运行的办公电脑即可。
- CPU：双核处理器，主频2.0GHz以上
- 内存：4GB RAM（推荐8GB）
- 存储：充足磁盘空间用于视频文件存储

## 2.3 安装步骤

系统采用绿色免安装部署模式，解压后即可运行。

## 2.4 首次启动配置

首次启动时无需额外配置，系统将自动创建默认项目。配置文件存储于项目目录中，支持项目重建功能。

# 3 快速入门 - 视频剪辑

## 3.1 打开视频文件

### 方式一：拖拽打开（推荐）
直接将视频文件从系统拖拽到主页面，即可开始编辑。

### 方式二：菜单打开
通过"文件 → 打开视频文件"菜单项选择视频文件。

### 方式三：项目模式
如果有大量视频需要处理，可以创建项目批量管理：
1. "文件 → 创建项目" 或 "文件 → 打开项目"
2. 配置视频存储目录
3. 执行项目同步，导入所有视频

## 3.2 视频剪辑操作

### 3.2.1 基本流程

```
打开视频 → 播放定位 → 拆分片段 → 删除无用片段 → 导出结果
```

### 3.2.2 操作步骤

1. **打开视频**：拖拽视频文件到界面
2. **播放预览**：使用播放控制浏览视频内容
3. **定位分割点**：播放到需要分割的位置，暂停
4. **拆分片段**：点击"拆分片段"按钮，在当前位置创建分割点
5. **删除片段**：选中不需要的片段，点击"删除片段"
6. **导出结果**：点击"导出剪辑"，生成新视频文件

### 3.2.3 操作按钮说明

| 按钮 | 功能描述 |
|-----|---------|
| 切换视图 | 在视频模式和缩略图模式之间切换 |
| 拆分片段 | 在当前播放位置拆分视频为一个新片段 |
| 移除拆分 | 移除当前选中片段的拆分点（合并相邻片段） |
| 删除片段 | 逻辑删除当前选中片段（标记为删除状态） |
| 恢复片段 | 恢复之前删除的片段 |
| 导出剪辑 | 导出未删除的片段为新视频文件 |

## 3.3 视频预览与定位

### 3.3.1 播放控制

| 操作 | 说明 |
|-----|------|
| 播放/暂停 | 空格键或点击播放按钮 |
| 停止 | 停止播放，回到起始位置 |
| 倍速播放 | 0.5x / 1x / 2x / 4x 倍速 |
| 进度条拖拽 | 快速定位到任意位置 |

### 3.3.2 帧精确定位

| 操作 | 说明 |
|-----|------|
| 下一帧 | 精确前进一帧 |
| 上一帧 | 精确后退一帧 |
| 关键帧跳转 | 跳转到上一个/下一个关键帧 |

### 3.3.3 缩略图视图

切换到缩略图视图，可以：
- 快速浏览视频关键帧
- 点击缩略图跳转到对应位置
- 直观了解视频内容分布

# 4 文件管理功能

## 4.1 运行模式

系统支持两种运行模式：

| 模式 | 说明 | 功能 |
|-----|------|------|
| **文件编辑模式** | 直接打开单个视频文件 | 仅提供视频分片编辑功能 |
| **项目模式** | 打开或创建项目后进入 | 完整的文件管理、标签管理、缩略图生成等功能 |

**模式切换：**
- 通过"文件 → 打开视频文件"或拖拽视频文件进入文件编辑模式
- 通过"文件 → 创建项目"或"文件 → 打开项目"进入项目模式

## 4.5 项目设置

![功能管理页面 (Admin) 项目设置](image/readme-zh/admin_setting.jpg)

## 4.6 基本操作流程

### 4.6.1 项目模式流程

1. **项目初始化**：创建新项目，配置视频存储路径和项目路径
2. **数据同步**：执行项目同步，将视频文件信息录入数据库，同时生成缩略图和录像关键帧数据
3. **内容管理**：返回主界面进行视频文件的浏览与管理
4. **视频编辑**：选择视频进行分片编辑

### 4.6.2 文件编辑模式流程

1. **打开文件**：拖拽视频文件或通过菜单打开
2. **分片编辑**：拆分、删除、恢复片段
3. **导出结果**：导出剪辑后的视频

### 4.6.3 数据删除策略

- 正常模式下删除：文件移至回收站，保留预览资源
- 回收站模式下删除：执行物理删除，可选择性清除预览资源

支持视频内容分级标注，便于后续批量处理与检索。

# 5 高级功能

## 5.1 关键帧提取

系统自动提取视频关键帧：
- 按时间间隔提取（如每5秒一帧）
- 按文件大小提取（如每1MB一帧）
- 生成缩略图网格，快速预览

## 5.2 智能压缩策略

针对低优先级视频文件，系统可执行关键帧抽取策略，在保留核心信息的同时显著降低存储占用。此类文件在列表中以特殊标识显示，仅支持预览模式。

## 5.3 批量处理

支持多选视频文件进行批量标注、删除、导出等操作，提升工作效率。

## 5.4 搜索与过滤

提供多维度搜索功能，支持按时间范围、文件大小、标签、评级等条件进行精确过滤。

# 7 常见问题

## 7.1 如何快速剪辑视频？

1. 拖拽视频到界面
2. 播放并定位分割点
3. 拆分 → 删除无用片段 → 导出

## 7.2 如何批量处理监控录像？

1. 创建项目，导入所有录像
2. 使用缩略图视图快速浏览
3. 标记有价值的片段
4. 批量删除无用录像

## 7.3 如何恢复误删的片段？

在编辑面板的分片列表中，选中已删除的片段，点击"恢复片段"即可。

## 7.4 导出的视频在哪里？

导出时可以选择保存位置，默认保存在项目工作目录的 output 文件夹中。
