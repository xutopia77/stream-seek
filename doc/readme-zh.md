# StreamSeek 使用手册

# 1 简介

StreamSeek 是一款专业的视频流分析与录像管理系统，专为安防监控录像文件管理而设计。该软件提供视频播放控制、分片编辑、文件管理、标签分类、缩略图生成等核心功能。特别适合管理小米摄像头等智能设备的录像文件。

# 2 设计目标

本系统旨在解决视频处理中的核心需求：
- **视频片段快速剪辑**：精准定位、拆分、删除、导出
- **关键内容提取**：自动提取关键帧，快速预览视频内容
- **批量视频处理**：支持多文件管理与批量操作
- **存储空间优化**：智能压缩策略，保留核心信息

# 3 核心功能

## 3.1 视频播放控制

- **标准播放**
  播放/暂停、进度跳转、音量控制
- **倍速播放**：
  支持 0.5x ~ 6x 倍速播放，快速浏览
- **逐帧播放**：
  精确到单帧的前进/后退，精准定位
- **进度控制**：
  拖动进度条快速定位，显示当前时间/总时长
- **拖拽打开**：
  直接拖拽视频文件到界面即可播放


## 3.2 视频分片编辑

- **分片拆分**：
  在播放位置精准拆分视频片段，方便剪辑。
- **片段删除**：
  标记删除不需要的视频片段，避免误删。
- **片段恢复**：
  恢复误删的视频片段，确保数据安全。
- **导出剪辑**：
  将保留的视频片段导出为新视频文件，方便分享或编辑。
- **截图导出**：
  导出当前播放帧为 JPG/PNG 图片，方便记录关键帧。

## 3.3 文件管理

- **项目管理**
  创建项目批量管理视频文件。
- **自动扫描**
  扫描文件夹，批量导入视频文件。
- **等级标签**
  为视频添加等级标签（1-5星），便于分类检索。
- **回收站**
  软删除机制，防止误删。
  正常模式下删除：文件移至回收站，保留预览资源。
  回收站模式下删除：执行物理删除，可选择性清除预览资源。
- **搜索过滤**
  按时间、等级、大小等条件筛选。


## 3.4 缩略图管理

- **自动生成**：
  从视频中提取关键帧作为缩略图，方便浏览视频内容。
- **缩略图视图**：
  点击缩略图跳转到对应播放位置，方便快速定位。
- **尺寸调节**：
  支持调整缩略图卡片大小（2-8列），方便查看。
- **快速定位**：
  点击缩略图跳转到对应播放位置，方便快速定位。

## 3.5 视频分析

### 3.5.1 媒体信息查看
查看视频文件的基本信息：
- 文件名、大小、时长
- 视频分辨率、编码格式
- 帧率、比特率
- 创建时间、修改时间

![媒体信息页面](https://imgbed.xutopia.top/image-assets/95414ab4abdf72d2341557c3af479640.jpg)

### 3.5.2 MP4 Box 分析

解析 MP4 文件结构，查看文件容器信息：
- 文件盒（Box）结构树形展示
- 各个 Box 的详细信息
- 元数据（Metadata）内容

分析视频帧信息：
- 总帧数、帧率
- 编码格式、分辨率
- I帧、P帧、B帧分布
- 帧大小、时间戳信息

# 4 适用场景

- **视频剪辑**：快速裁剪视频，移除冗余内容，保留精彩片段
- **监控录像处理**：筛选有价值的监控片段，删除无用录像
- **视频内容分析**：通过关键帧快速了解视频内容
- **存储空间优化**：删除冗余视频，释放存储空间

# 5 支持格式

支持常见的视频格式：
- `.mp4`, `.avi`, `.mkv`, `.mov`, `.wmv`, `.flv`, `.webm`

# 6 安装与使用

系统采用绿色免安装部署模式，解压后即可运行。

首次启动时无需额外配置，系统将自动创建默认项目。配置文件存储于项目目录中，支持项目重建功能。
